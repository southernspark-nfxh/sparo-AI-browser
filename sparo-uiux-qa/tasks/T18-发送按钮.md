## 二、shell.html 改法

### 2.1 SVG sprite 加纸飞机图标

找到现有 `<symbol id="i-send" ...>`（注意不是新增，**检查有没有，有就复用**）。搜索 `i-send`，如果已经有纸飞机/发送图标，直接用它，不要重画。

**若找不到**，参考现有 sprite 的格式追加（`viewBox="0 0 24 24"`、`fill="none"`、`stroke="currentColor"`、`stroke-width="1.6"`、`stroke-linecap="round"`、`stroke-linejoin="round"`）：

```xml
<symbol id="i-paper-plane" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.6" stroke-linecap="round" stroke-linejoin="round">
  <path d="M22 2L11 13"/>
  <path d="M22 2l-7 20-4-9-9-4 20-7z"/>
</symbol>
```

> 附件图标（回形针）同理，如果已有就复用 `i-clip` / `i-attach`，没有就追加。

### 2.2 `go-row` DOM（原样替换 L1876 那行）

现有：

```html
<div class="go-row"><button type="button" class="ghost" id="chatFile" data-i18n="chat.file" title="选一个本地文件，或直接把文件拖进来">文件</button><button type="button" id="chatSend" data-i18n="chat.send">让它动手</button></div>
```

改成：

```html
<div class="go-row">
  <button type="button" class="icon-btn ghost" id="chatFile" data-i18n-title="chat.file" title="选一个本地文件，或直接把文件拖进来" aria-label="文件">
    <svg class="ic"><use href="#i-attach"/></svg>
  </button>
  <button type="button" class="send" id="chatSend" data-i18n-title="chat.send" title="发送 (Ctrl+Enter)" aria-label="发送">
    <svg class="ic"><use href="#i-paper-plane"/></svg>
  </button>
</div>
```

要点：
- 发送按钮**只留图标，不显示文字**（用户说「发送」或按键符号都行，走符号）。
- 文件按钮改成 `.icon-btn ghost`，和顶栏的收藏星、⋯ 菜单同款圆形 icon-btn。
- 两个按钮都用 `data-i18n-title`（悬停提示），**不再**用 `data-i18n`（按钮内文字）。原因：`applyDom` 会把 `textContent` 覆盖掉 SVG `<use>`，图标会消失。
- 发送按钮加 `class="send"`，走渐变胶囊 + 发光（T16 那套 `.primary, .send, .ok, #chatSend` 已经在 `:hover` 里了，新写的 `.send` 也要进那组选择器）。

### 2.3 `.go-row` CSS 调整

现有：

```css
.go-row { display: flex; justify-content: flex-end; gap: 8px; align-items: center; }
```

改成：

```css
.go-row {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding-top: 6px;
}
.go-row .icon-btn.ghost {
  width: 32px;
  height: 32px;
  border-radius: 50%;
}
.go-row #chatSend.send {
  width: 38px;
  height: 38px;
  border-radius: 50%;
  background: var(--grad);
  border: 0;
  color: var(--accent-ink);
  cursor: pointer;
  display: inline-flex;
  align-items: center;
  justify-content: center;
  box-shadow: var(--glow);
  transition: transform .12s ease, box-shadow .12s ease, filter .12s ease;
}
.go-row #chatSend.send:hover {
  filter: brightness(1.08);
  box-shadow: 0 8px 22px color-mix(in srgb, var(--accent) 34%, transparent);
}
.go-row #chatSend.send:active { transform: translateY(1px); }
.go-row #chatSend.send:disabled {
  background: var(--line);
  box-shadow: none;
  cursor: not-allowed;
  opacity: .55;
}
```

要点：
- 发送按钮改成 **38px 圆形渐变胶囊**，只显示纸飞机图标；和顶栏主按钮的渐变/发光保持一套变量（`--grad` / `--accent-ink` / `--glow`）。
- 文件按钮 32px 圆形 ghost；灰色悬停跟顶栏 icon-btn 一致（`.icon-btn:hover { background: color-mix(in srgb, var(--text) 7%, transparent); color: var(--text); }` 已经存在，直接复用）。
- `#chatSend` **不要**同时挂在 `.primary, .save, .ok, #chatSend, .go, .reply-one` 那组选择器上了（T16 改的那组），那组现在是渐变胶囊方形按钮。给发送按钮单独写 `.go-row #chatSend.send` 这一条（圆形是特例）。

### 2.4 底部提示那句「网页上的发送，始终由你点」
