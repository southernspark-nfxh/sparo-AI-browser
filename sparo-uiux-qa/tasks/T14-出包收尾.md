## 3. 用真实样本核对报告页

**为什么**：T09 只做了静态色值核对，没有拿真实报告页肉眼看过。

**步骤**：

1. `npm run start`。
2. 侧栏输入一句会触发长文产出的任务，例如「帮我总结这篇文章」（先在网页区打开一篇长文），或跑一次简单的筛选/对比任务。
3. 产物页会在窗口里打开。核对四点：
   - 页面底色是纸色，不是旧的红白或冷灰；
   - 主按钮是烧赭，不是蓝色；
   - 标题/正文/次要文字层级清楚，没有 11px 小字；
   - 打印或另存 PDF 时版式不塌。
4. 截图存到 `d:\download\sparo上架应用商店版\sparo-uiux-qa\screens\report-page.png`（目录不存在就建）。
5. **发现偏色才改** `src\main\agent\report-html.ts`，改完重看一遍。没偏色就不要动文件。

```text
[ ] 安装后从桌面打开，窗口正常，不是空白
[ ] 顶部两行，没有书签栏；标签有站点图标
[ ] ⋯ 菜单是系统菜单，四项都能点
[ ] 侧栏左边缘 8px 能拖宽，双击回 340，收起 56px，Ctrl+\ 能展开
[ ] 设置三段（常用/经验/高级）切换无空白
[ ] 未配置模型时，锁屏只有「去设置模型」，点它直达设置
[ ] 网页区尺寸正常，没有被压成窄条（最小化→还原后再看一次）
[ ] GET http://127.0.0.1:3921/health 返回 ok
```

有任何一条不过：不要改安装包，退回代码修，重新 `npm run dist`。
