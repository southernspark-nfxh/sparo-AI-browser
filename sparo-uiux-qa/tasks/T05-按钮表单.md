# T05 · 按钮收敛为 4 级 + 表单语言统一

> 工作根目录（绝对路径）：`d:\download\sparo上架应用商店版`
> 唯一改动文件：`d:\download\sparo上架应用商店版\src\renderer\shell.html`
> 前置：T01 已提交（令牌已就位）
> 风险：中（只改 CSS 与少量 class 归组，不改 id、不改 onclick）

---

## 0. 现状问题

- 全文件有 **14 种**按钮写法：`.save`、`.primary`、`.ok`、`.gear`、`.done`、`.job`、`.choice`、`.mode-card`、`.user-chip`、`.go`、`.reply-one`、`#chatSend`、`.ghost`、`.danger`，高度 26/28/30/32/36 混用，圆角 8/999 混用。
- 表单有两套语言：地址栏是**胶囊填色**，设置抽屉是**下划线**（`border-bottom: 1px solid`），composer 是**大圆角容器**。
- 主按钮颜色靠 `var(--accent)` 近黑，和正文同色，层级不清楚（T01 已改烧赭）。

目标不是换 class 名，而是**把散落的规则合并成 4 级**。

---

## 1. 目标

1. 按钮只有 4 级语义：**Primary / Secondary / Ghost / Danger**。
2. 所有按钮高度统一 **32px**，圆角 **10px**（地址栏、用户胶囊、Toast 保留胶囊）。
3. 按钮字号 13px、主按钮字重 600。
4. 所有输入框统一：填色底 + 1px 边 + 10px 圆角 + 品牌色 focus 环。
5. 地址栏仍是胶囊（浏览器惯例），但焦点态用品牌色。
6. 不改任何 `id`、`onclick`、DOM 层级。

---

## 2. 具体改动

### 2.1 新增基础层（加在 `<style>` 末尾，靠后覆盖）

```css
/* ---------- buttons: 4 levels ---------- */
.primary, .save, .ok, #chatSend, .go, .reply-one {
  background: var(--accent);
  border: 1px solid var(--accent);
  color: var(--accent-ink);
  font-weight: var(--fw-sb);
}
.primary:hover, .save:hover, .ok:hover, #chatSend:hover, .go:hover, .reply-one:hover:not(:disabled) {
  background: color-mix(in srgb, var(--accent) 88%, #000);
  border-color: color-mix(in srgb, var(--accent) 88%, #000);
}
.primary:active, .save:active, .ok:active, #chatSend:active, .go:active {
  transform: translateY(1px);
}

/* 统一尺寸：所有实心/描边/幽灵按钮 */
.save, .ok, .primary, .go, .reply-one, .gear, .done,
.sidebar button.ghost, .welcome button.ghost, .composer-lock button.ghost,
.user-pop button.ghost, .sidebar button.danger, .shortcuts .job, .thread-tools button {
  height: 32px;
  padding: 0 12px;
  border-radius: var(--r-10);
  font-size: var(--fs-13);
  line-height: 1;
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: 6px;
  cursor: pointer;
}

/* secondary：描边填色 */
.gear, .done, .welcome button.ghost, .composer-lock button.ghost, .user-pop button.ghost {
  background: var(--paper);
  border: 1px solid var(--line);
  color: var(--text);
}
.gear:hover, .done:hover, .welcome button.ghost:hover,
.composer-lock button.ghost:hover, .user-pop button.ghost:hover {
  border-color: color-mix(in srgb, var(--text) 28%, var(--line));
}

/* ghost：无底无边 */
.sidebar button.ghost, .thread-tools button, .shortcuts .job {
  background: transparent;
  border: 1px solid transparent;
  color: var(--muted);
  padding: 0 8px;
}
.sidebar button.ghost:hover, .thread-tools button:hover, .shortcuts .job:hover {
  color: var(--text);
  background: color-mix(in srgb, var(--text) 6%, transparent);
}

/* danger */
.sidebar button.danger {
  background: transparent;
  border: 1px solid transparent;
  color: var(--bad);
}
.sidebar button.danger:hover { background: color-mix(in srgb, var(--bad) 10%, transparent); }

/* 抽屉里的主按钮：满宽 */
.sidebar .save, .sidebar .primary, .sidebar #btnDsSave, .sidebar #btnPfSave, .sidebar #btnCopyAgent {
  width: 100%;
}
.row button.save, .approval .row button.ok { width: auto; }
```

### 2.3 表单：从下划线改成填色框

替换（L1031-1045）：

```css
.field input, .field select,
.block input, .block select,
.lang-row select {
  width: 100%;
  height: 36px;
  padding: 0 10px;
  border: 1px solid var(--line);
  border-radius: var(--r-10);
  background: var(--paper);
  color: var(--text);
  font-size: var(--fs-13);
  outline: none;
}
.field input:hover, .field select:hover,
.block input:hover, .block select:hover { border-color: color-mix(in srgb, var(--text) 24%, var(--line)); }

.field input:focus, .field select:focus,
.block input:focus, .block select:focus,
.lang-row select:focus,
.history-head input:focus,
.notes-panel input:focus,
.find-bar input:focus {
  border-color: var(--accent);
  box-shadow: 0 0 0 3px color-mix(in srgb, var(--accent) 14%, transparent);
}
```

`label` 保持 12px / `--muted`，与控件间距 6px：

```css
.field { gap: 6px; margin-bottom: 14px; }
```

`.idle-row input`（内存分钟数）原本也是下划线，改成同样的小填色框：

```css
.idle-row input {
  width: 64px; height: 32px;
  text-align: center;
  border: 1px solid var(--line);
  border-radius: var(--r-10);
  background: var(--paper);
}
```

### 2.4 地址栏

保留胶囊，但统一尺寸与焦点：

```css
.url {
  height: 32px;
  border-radius: var(--r-999);
  padding: 0 14px;
  font-size: var(--fs-13);
}
.url:focus {
  border-color: var(--accent);
  box-shadow: 0 0 0 3px color-mix(in srgb, var(--accent) 14%, transparent);
}
```

`.nav button, .icon-btn` 高度同步到 30px（T02 已设），与 32px 地址栏垂直居中即可。

### 2.5 卡片选择（模式卡）

`.mode-card` 是"选择卡片"，不算按钮，保持 12px 圆角与 1px 边，只统一内边距：

```css
.mode-card { border-radius: var(--r-16); padding: 12px; }
.mode-card.on { border-color: var(--accent); background: var(--accent-soft); }
.mode-card strong { font-size: var(--fs-13); font-weight: var(--fw-sb); }
.mode-card span { font-size: var(--fs-12); }
```

### 2.6 禁用态

```css
button:disabled { opacity: .45; cursor: not-allowed; transform: none; }
```

## 3. 红线

- 不许改任何 `id` / `onclick` / `data-i18n`。
- 不许改按钮文案。
- 不许把 `.user-chip`、`.toast`、`.switch .track` 改成方形——它们是真胶囊。
- 不许改 `.mode-card` 的 DOM 结构。
- 不许引入新的按钮 class 名到 DOM 里（只在 CSS 层归组，减少回归风险）。
- 不许删 `.composer` 的 16px 圆角。
