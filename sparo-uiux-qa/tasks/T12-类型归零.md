## 1. `travel.ts` 路线 union 没窄化

**文件**：`d:\download\sparo上架应用商店版\src\main\agent\travel.ts` L990

**现象**：

```ts
return [
  `根据下面地图/路线正文，用中文说明从 ${q.from} 到 ${q.to} 怎么走：…`,
```

但 `q` 的联合类型里有 `{ kind: "search"; site: "baidu"; query: string }`，没有 `from` / `to`。

**改法**：读同函数上方已有的分支（`q.kind === "venue"` / `"flight"` / `"train"`），按同样风格在最后一段前补 `search` 分支（用 `q.query` 写提示词），再把地图分支收窄成 `q.kind === "maps"`。

**不许**用 `(q as any).from`。

## 2. `runtime.ts` 把 `string | null` 传给只收 `string` 的函数

**文件**：`d:\download\sparo上架应用商店版\src\main\agent\runtime.ts` L239

**现状**：

```ts
const cityHit = findCities(t).map(canonCity).find((c) => isCity(c));
```

`findCities()` 的返回里带 `null`。

**改法**：在 `map` 前过滤，保持原语义：

```ts
const cityHit = findCities(t)
  .filter((c): c is string => Boolean(c))
  .map(canonCity)
  .find((c) => isCity(c));
```

如果 `findCities` 的真实返回类型不是 `(string | null)[]`，以类型定义为准，选能真实窄化的写法。不要改 `canonCity` 签名。

## 3. `reasoner.ts` 的 `Set` 收窄过头

**文件**：`d:\download\sparo上架应用商店版\src\main\agent\kernel\reasoner.ts` L37

**现状**：

```ts
const excluded = new Set(goal.known.exclude || []);
```

`goal.known.exclude` 是 `KnownBlock[]`，但下面 `missing` 里的 id 是更宽的 `"form" | "video" | "page" | …`，`excluded.has(id)` 直接报错。

**改法**：声明成 `const excluded = new Set<string>(goal.known.exclude || []);`。`prefer` 那行同理，如果也报错就 `const prefer = (goal.known.prefer || []) as string[];`——只放宽集合类型，不改判断逻辑。

**现状**：

```ts
for (const id of missing) {
```

**改法**：删掉 `else if (id === "itinerary" && city) { … }` 这两行。上面的 `continue` 已经把 itinerary 排除了。

## 6. `browser.ts` 的 `unminimize` 重载错误

**文件**：`d:\download\sparo上架应用商店版\src\main\browser.ts` L647

**现状**：

```ts
// Windows 上最小化→恢复不一定补一次有效 resize（事件可能在尺寸还是 0 时触发），
// 显式监听并延迟补排，防止页面视图停在 100px 窄条。
this.window.on("unminimize", () => this.scheduleLayout(150));   // ← TS2769
this.window.on("restore", () => this.scheduleLayout(150));
this.window.on("show", () => this.scheduleLayout(150));
```

`unminimize` 不在 Electron `BrowserWindow` 的事件类型里（`restore` 才是"从最小化恢复"）。

**先查**：Electron 35 的 `BrowserWindow` 是否真发 `unminimize` 事件（在 `node_modules\electron\electron.d.ts` 里搜 `unminimize`）。

- **搜不到** → 删掉 `unminimize` 这一行，保留 `restore` + `show`。删掉后**实机验证**：最小化 → 还原 → 网页区不能变成 100px 窄条（这是当年出过事故的点）。
- **搜得到** → 以官方声明的写法为准修正监听（不要用 `as any`）。
