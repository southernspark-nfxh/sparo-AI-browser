# T17 · 标签栏溢出与顶栏高度自洽

> 工作目录：`d:\download\sparo上架应用商店版`
> 前置：T16 已合入（或还没合入，就并到 T16 那次一起做，一个 commit）。
> 问题：标签多开后，顶栏被撑高，网页 WebContentsView 的 Y 起点没跟着下移，导致网页顶部被顶栏盖住。
> 根因纯 CSS：`.tab` 有 `min-width: 80px`，阻止 flex 收缩；`.tabs-row` 没有 `overflow: hidden` 兜底。

## 一、改什么，原样抄（只改 `src/renderer/shell.html`）

### 1.1 `.tab` 让它能真收缩

现有：

```css
.tab {
  display: flex;
  align-items: center;
  gap: 6px;
  max-width: 180px;
  min-width: 80px;
  ...
}
```

改成：

```css
.tab {
  display: flex;
  align-items: center;
  gap: 6px;
  flex: 0 1 160px;
  min-width: 36px;
  max-width: 180px;
  ...
}
```

**变化**：
- 去掉硬的 `min-width: 80px`，降到 `36px`（能装下 favicon + 关闭按钮）。
- 加 `flex: 0 1 160px`：正常 160px，能缩、不能撑。

### 1.2 `.tabs-row` 补 overflow 兜底

现有（L153 起）：

```css
.tabs-row {
  grid-column: 1 / -1;
  grid-row: 1;
  display: flex;
  align-items: stretch;
  ...
}
```

在这个块的末尾加：

```css
  overflow: hidden;
```

作用：哪怕 `.tab` 的收缩逻辑没起到作用，标签也不能冲出顶栏行。

### 1.3 `.tabs` 加滚动条样式，让用户看得见

现有 `.tabs` 有 `overflow-x: auto`，但 Electron 里默认滚动条极窄，用户看不出可以横向滚。加：

```css
.tabs::-webkit-scrollbar { height: 4px; }
.tabs::-webkit-scrollbar-thumb {
  background: var(--line-strong);
  border-radius: 2px;
}
.tabs::-webkit-scrollbar-track { background: transparent; }
```

### 1.4 不用动的东西（写死，不许动）

- `.app` 的 `grid-template-rows: env(titlebar-area-height, 36px) 40px 1fr`
- `CHROME_H = 76`（browser.ts L425）
- 主进程的 `pageBounds()` / `applyViewBounds()` / `spark:page-hole` IPC
- `.bar` 的高度 40px
- `--chrome-h: 76px`（shell.html 里的变量）

改完顶栏行高**必须**保持 76px 不变——36（tabs）+ 40（omnibox）。
