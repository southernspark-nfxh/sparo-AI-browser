## 0. 必须先看懂这段

主进程 `pageBounds()` 里写着：

```ts
// L1584-1586（现状）
// 洞的宽/x 由 shell 的固定 grid 唯一决定（1fr + 312px 侧栏）……
const viewW = Math.max(100, width - SIDEBAR_W);
```

也就是说：**网页宽度 = 窗口宽 − 常量 312**，它故意不采信渲染进程上报的洞宽（曾经被夹成 100px 出过事故）。
所以侧栏要能变宽，**必须让主进程知道新宽度**，不能靠 shell 自己改 CSS 就完事。

做法：新增一个专用 IPC，主进程保存 `sidebarW`（带夹取），`pageBounds` 用它代替常量。

---

## 1. 目标

1. 侧栏默认 340px，可拖 300–480px。
2. 可收成 56px 竖向工具轨，再点回来。
3. 宽度与收起状态重启后保留。
4. `Ctrl+\` 收起/展开。
5. 拖拽过程不卡、不抖，网页区实时跟随。
6. 任何情况下网页区宽度 ≥ 100px。

```ts
setSidebarWidth: (w: number) => ipcRenderer.send("spark:set-sidebar-width", w),
```

不要加 invoke，用 send 就够（不需要回值）。

## 3. 改动 B：`browser.ts`

### 3.1 加字段

在 `private holeBounds`（L530）附近加：

```ts
private sidebarW = SIDEBAR_W;
```

### 3.2 注册 IPC

在 `ipcMain.on("spark:page-hole", ...)`（L1728-1729）下面加：

```ts
ipcMain.removeAllListeners("spark:set-sidebar-width");
ipcMain.on("spark:set-sidebar-width", (_e, raw) => {
  const w = Math.round(Number(raw));
  if (!Number.isFinite(w)) return;
  const next = Math.min(480, Math.max(300, w));
  if (next === this.sidebarW) return;
  this.sidebarW = next;
  this.layout();
});
```

### 3.3 `pageBounds` 用它

```ts
const viewW = Math.max(100, width - this.sidebarW);
```

同时把 L1584 的注释改成「洞宽由窗口宽减可调侧栏宽决定，侧栏宽度由 spark:set-sidebar-width 下发并夹取」。

**其余逻辑一律不动**：`b.y` 的区间检查、`b.height` 的兜底、`lastGoodContent` 全部保留。

### 4.3 收起态宽度

```css
body.side-collapsed { --side-w: 56px; }
body.side-collapsed .side-resizer { display: none; }
```

`--side-w` 默认值在 T01 里是 312；本任务把 `:root` 改成 `340px`，并把主进程 `SIDEBAR_W` 也改成 **340**（两处必须一致，否则首帧会闪一下）。

### 4.4 交互 JS

在 `window.sparkShell` 初始化之后（约 L3000 附近，`reportHole` 定义前后）加：

```js
const SIDE_MIN = 300, SIDE_MAX = 480, SIDE_COLLAPSED = 56;
const rootEl = document.documentElement;
const resizer = document.getElementById("sideResizer");

function currentSideWidth() {
  const raw = getComputedStyle(rootEl).getPropertyValue("--side-w").trim();
  return parseInt(raw, 10) || 340;
}
function applySideWidth(w, { persist = true, collapse = false } = {}) {
  const next = collapse ? SIDE_COLLAPSED : Math.min(SIDE_MAX, Math.max(SIDE_MIN, Math.round(w)));
  rootEl.style.setProperty("--side-w", next + "px");
  document.body.classList.toggle("side-collapsed", collapse);
  if (window.sparkShell && window.sparkShell.setSidebarWidth) {
    window.sparkShell.setSidebarWidth(next);
  }
  if (persist) {
    localStorage.setItem("sparo.side.w", String(next));
    localStorage.setItem("sparo.side.collapsed", collapse ? "1" : "0");
  }
  return next;
}

let dragging = false, dragStartX = 0, dragStartW = 0, dragRaf = 0, dragLast = 0;
resizer.addEventListener("pointerdown", (e) => {
  if (document.body.classList.contains("side-collapsed")) return;
  dragging = true;
  dragStartX = e.clientX;
  dragStartW = currentSideWidth();
  document.body.classList.add("side-resizing");
  resizer.setPointerCapture(e.pointerId);
});
resizer.addEventListener("pointermove", (e) => {
  if (!dragging) return;
  dragLast = dragStartW + (dragStartX - e.clientX);
  if (dragRaf) return;
  dragRaf = requestAnimationFrame(() => {
    dragRaf = 0;
    applySideWidth(dragLast, { persist: false });
  });
});
function endDrag() {
  if (!dragging) return;
  dragging = false;
  document.body.classList.remove("side-resizing");
  applySideWidth(dragLast || currentSideWidth(), { persist: true });
}
resizer.addEventListener("pointerup", endDrag);
resizer.addEventListener("pointercancel", endDrag);
resizer.addEventListener("dblclick", () => {
  if (document.body.classList.contains("side-collapsed")) return;
  applySideWidth(340, { persist: true });
});

document.getElementById("sideExpand").onclick = () => {
  const saved = Number(localStorage.getItem("sparo.side.w") || 340);
  applySideWidth(saved >= SIDE_MIN ? saved : 340, { persist: true, collapse: false });
};
document.querySelectorAll(".rail-btn[data-job]").forEach((btn) => {
  btn.onclick = () => {
    const saved = Number(localStorage.getItem("sparo.side.w") || 340);
    applySideWidth(saved >= SIDE_MIN ? saved : 340, { persist: true, collapse: false });
    const target = document.getElementById(btn.dataset.job);
    if (target) setTimeout(() => target.click(), 60);
  };
});

// 启动时恢复
(function restoreSide() {
  const collapsed = localStorage.getItem("sparo.side.collapsed") === "1";
  const saved = Number(localStorage.getItem("sparo.side.w") || 340);
  if (collapsed) applySideWidth(SIDE_COLLAPSED, { persist: false, collapse: true });
  else if (saved) applySideWidth(saved, { persist: false });
})();

// Ctrl+\ 收起/展开
document.addEventListener("keydown", (e) => {
  if ((e.ctrlKey || e.metaKey) && e.key === "\\") {
    e.preventDefault();
    const collapsed = document.body.classList.contains("side-collapsed");
    const saved = Number(localStorage.getItem("sparo.side.w") || 340);
    applySideWidth(collapsed ? (saved >= SIDE_MIN ? saved : 340) : SIDE_COLLAPSED, {
      persist: true,
      collapse: !collapsed,
    });
  }
});
```

## 5. 红线

- **主进程夹取 300–480 必须存在**，不许只在前端限制。
- **`Math.max(100, ...)` 必须保留。**
- 不许改 `setPageHoleBounds` 的校验逻辑（`width >= 80 && height >= 80`）。
- 不许把 `--side-w` 做成百分比或 `min-content`。
- 不许在拖拽每一帧都发 IPC——只在 `pointerup` 和收起/展开时发（上面的 rAF 只改 CSS）。
- 不许改 `SIDEBAR_W` 以外的任何主进程布局常量。
- 不许给 `.rail-btn` 复制 `btnSummarize` 等 id（必须用 `data-job` 转发点击）。
