## 一、总目标（一句话）

不重做架构，只做收敛：**一套图标、一套按钮、一套表单、两行 Chrome、一个登录入口、可收起的侧栏**。
做完后用户第一眼能看懂"这是浏览器 + 右边有人帮我干活"，而不是"一个塞满按钮的工具箱"。

## 三、全局红线（每本任务书都适用，违反即打回）

1. **只改任务书列出的文件。** 其他文件一行都不许动。
2. **不许新增 npm 依赖。** 不引入 Tailwind、React、图标库、远程字体、CDN。
3. **不许动 `docs/listings/`。** 提审文案另做一轮。
4. **不许把云端密钥写进客户端。** 商店版不出现价格、套餐、支付 UI（`docs/PRICING.md` 的货架只在官网）。
5. **不许改 MCP 工具名与参数。** `http://127.0.0.1:3921` 的行为必须保持。
6. **不许删 `data-i18n` / `data-i18n-title` 属性。** 中英文都要还能切。
7. **不许让主进程依赖渲染进程发来的可疑数值。** `pageBounds` 的 100px 夹取保护必须保留。
8. **每本任务书一次 commit，不许裸改堆在一起。**
9. **改完必须自己启动点一遍**（`npm run start`），点不到的按钮不算完成。
10. **不许顺手"优化"无关代码。** 看到别的丑地方，写进反馈，不要动。
