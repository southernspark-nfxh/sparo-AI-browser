## 1. 目标（可验收）

1. `:root` 成为唯一色值/字号/字重/圆角来源，后续任务只引用变量。
2. 全文件不再出现 `font-weight: 560 / 620 / 650`。
3. 全文件不再出现 `font-size: 10px / 11px`。
4. 圆角只剩 8 / 10 / 16 / 999 四档。
5. 阴影只剩两级变量。
6. 品牌色改为烧赭 `#a34a1e`，并与正文近黑 `#1c1a18` 拉开。
7. **不改任何布局尺寸**：`--chrome-h` 仍为 `104px`，`--side-w` 仍为 `312px`（留给 T03/T04）。

## 2. 具体改动

### 2.1 用下面整块替换现有 `:root`

```css
:root {
  color-scheme: light;

  /* 纸面 */
  --page: #e4e0dc;
  --bg: #eeeae6;
  --bg2: #eeeae6;
  --side: #f3f0ec;
  --paper: #fbfaf8;
  --line: #ddd8d2;
  --surface-2: #e8e4e0;      /* 原来散落的 #e8e4e0 */

  /* 文字 */
  --text: #1c1a18;
  --muted: #6e6a66;

  /* 品牌 */
  --accent: #a34a1e;
  --accent-ink: #fffaf6;
  --accent-soft: #f6ece5;    /* 浅底，用于需要底色的标签/提示 */
  --ok: #4d7a55;
  --warn: #96742e;
  --bad: #a8433a;

  /* 字号 */
  --fs-12: 12px;
  --fs-13: 13px;
  --fs-14: 14px;
  --fs-16: 16px;
  --fs-20: 20px;

  /* 字重 */
  --fw-r: 400;
  --fw-m: 500;
  --fw-sb: 600;
  --fw-b: 700;

  /* 圆角 */
  --r-8: 8px;
  --r-10: 10px;
  --r-16: 16px;
  --r-999: 999px;

  /* 间距 */
  --sp-1: 4px;
  --sp-2: 8px;
  --sp-3: 12px;
  --sp-4: 16px;
  --sp-5: 20px;
  --sp-6: 24px;

  /* 阴影 */
  --shadow-1: 0 6px 18px rgba(28, 26, 24, .10);
  --shadow-2: 0 14px 36px rgba(40, 32, 24, .16);

  /* 尺寸（本任务不改值） */
  --chrome-h: 104px;
  --side-w: 312px;

  --radius-btn: var(--r-999);
  --radius-in: var(--r-16);

  font-family: -apple-system, "SF Pro Text", "Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", sans-serif;
}
```

> 保留 `--paper`、`--composer` 的引用关系；`--composer` 若原值为 `#fbfaf8`，可保留为 `--composer: var(--paper);`。

### 2.6 品牌色落点（只改这三处，别扩散）

1. `.url:focus { border-color: var(--text); }` → `border-color: var(--accent);`
   同时补 `box-shadow: 0 0 0 3px color-mix(in srgb, var(--accent) 14%, transparent);`
2. `.icon-btn.on { color: #b0892c; }` → `color: var(--accent);`
3. `.mode-card.on { background: #e8e4e0; border-color: var(--text); }` → `background: var(--accent-soft); border-color: var(--accent);`

写死色值统一到变量（不改视觉，只做准备）：

## 3. 红线

- **不许改任何 DOM 结构、class 名、id、onclick。**
- **不许改 JS 逻辑。**
- **不许改 `--chrome-h` / `--side-w` 的值。**
- 不许把 `--accent` 用到背景大面积平铺（只用于主按钮、focus 环、选中态）。
- 不许顺手删 `--composer`、`--tab`、`--tab-active` 等被 JS 或别处引用的变量。
- 不许改 `src/main/**`、`src/shared/i18n.ts`。
