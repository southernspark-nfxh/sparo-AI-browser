# T06 · 设置抽屉三分区（常用 / 经验 / 高级）

> 工作根目录（绝对路径）：`d:\download\sparo上架应用商店版`
> 唯一改动文件：`d:\download\sparo上架应用商店版\src\renderer\shell.html`
> 前置：T05 已提交
> 风险：中（搬动 DOM 节点，id 全部保留，绑定不变）

---

## 0. 现状问题

设置抽屉是一整条长滚动：模型 → 连接 Agent → 工作偏好 → 经验 → 高级 → 语言 → 自检。
- 用户 90% 只想改模型，却要先划过"连接 Agent"这种开发者功能。
- `block`（模型/Agent/语言）和 `fold`（工作偏好/经验/高级）两种容器混用，层级看不出来。
- 自检结果（红绿条目）直接铺在用户面前，像内部测试工具。

---

## 1. 目标

1. 抽屉顶部一条三段切换：**常用 / 经验 / 高级**，默认「常用」。
2. 每个分区只放同类内容，切换后不出现长滚动。
3. 「连接 Agent」「内存」「语言」「自检」全部降到「高级」。
4. 自检默认折叠，不展开不显示红绿条目。
5. 所有 id、onclick、i18n 保持原样。
6. 记住上次停留的分区。

### 2.3 切换 JS

放在 `setMoreOpen`（L2653）后面：

```js
const DS_PANELS = ["common", "learn", "advanced"];
function setDsPanel(name) {
  const target = DS_PANELS.includes(name) ? name : "common";
  document.querySelectorAll(".ds-tab").forEach((b) => {
    const on = b.dataset.panel === target;
    b.classList.toggle("on", on);
    b.setAttribute("aria-selected", on ? "true" : "false");
  });
  document.querySelectorAll(".ds-panel").forEach((p) => {
    p.classList.toggle("hide", p.dataset.panel !== target);
  });
  try { localStorage.setItem("sparo.ds.panel", target); } catch (err) { /* ignore */ }
}
document.querySelectorAll(".ds-tab").forEach((b) => {
  b.onclick = () => setDsPanel(b.dataset.panel);
});

// 给 T07 用的统一入口：打开设置并停在指定分区
window.__sparoOpenSettings = (panel) => {
  setMoreOpen(true);
  setDsPanel(panel || "common");
};
```

启动恢复（放在 `setMoreOpen` 定义之后、初始化尾部）：

```js
try {
  const last = localStorage.getItem("sparo.ds.panel");
  if (last) setDsPanel(last);
} catch (err) { /* ignore */ }
```
