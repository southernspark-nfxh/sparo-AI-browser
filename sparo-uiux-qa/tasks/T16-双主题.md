## 一、设计定案（写死，不许自己发挥）

| 项 | 定案 |
|---|---|
| 默认主题 | **浅色 Studio**（`:root` 就是浅色） |
| 夜间主题 | **深色 Glacier**（`html[data-theme="dark"]` 覆盖） |
| 切换入口 | 地址栏右侧、`#btnStar` 左边，一个 16px 图标按钮 `#btnTheme` |
| 图标语义 | 当前浅色 → 显示**月亮**（点了进夜间）；当前深色 → 显示**太阳**（点了回白天） |
| 记忆 | `localStorage["sparo.theme"]`，值只有 `"light"` / `"dark"` |
| 缺省 | 没有这个 key、或值非法 → 一律当 `"light"` |
| 标题栏 | 必须跟当前主题同色，不能出现「浅色窗口 + 深色标题栏」 |
| 报告页 | 跟着主题走：浅色主题出浅色文档，夜间主题出夜间文档 |

**变量名全部沿用 T01 建立的，只改值；只新增 `--accent-2` / `--grad` / `--glow` / `--accent-hover` 四个。**

### 3.8 切换逻辑

在侧栏那段 module script 里（能拿到 `t` 的地方）加：

```js
const rootEl = document.documentElement;
const themeBtn = document.getElementById("btnTheme");

function currentTheme() {
  return rootEl.getAttribute("data-theme") === "dark" ? "dark" : "light";
}

function applyTheme(theme, persist) {
  const dark = theme === "dark";
  if (dark) rootEl.setAttribute("data-theme", "dark");
  else rootEl.setAttribute("data-theme", "light");

  const use = themeBtn && themeBtn.querySelector("use");
  if (use) use.setAttribute("href", dark ? "#i-sun" : "#i-moon");
  if (themeBtn) {
    themeBtn.setAttribute("aria-pressed", dark ? "true" : "false");
    themeBtn.setAttribute("data-i18n-title", dark ? "nav.themeToLight" : "nav.themeToDark");
    themeBtn.title = t(dark ? "nav.themeToLight" : "nav.themeToDark");
  }

  try { window.sparkShell?.setTheme?.(theme); } catch (err) { /* ignore */ }
  if (persist) { try { localStorage.setItem("sparo.theme", theme); } catch (err) { /* ignore */ } }
}

themeBtn?.addEventListener("click", () => {
  applyTheme(currentTheme() === "dark" ? "light" : "dark", true);
});

// 启动时同步一次：把标题栏颜色对齐到已保存的主题
applyTheme(currentTheme(), false);
```

要点：

- 启动时**必须**调一次 `applyTheme(..., false)`，否则主进程标题栏还停在浅色。
- `data-i18n-title` 要跟着改，切换语言时 `applyDom` 会自动重刷。
- 不要用 `document.body.dataset`，主题挂在 `<html>` 上。

### 5.2 新增 IPC，让切换时标题栏跟着变

在 `spark:set-sidebar-width` 那段注册的旁边加：

```ts
ipcMain.removeAllListeners("spark:set-theme");
ipcMain.on("spark:set-theme", (_e, raw) => {
  const dark = String(raw) === "dark";
  const bg = dark ? "#0d1117" : "#fbfbfd";
  const fg = dark ? "#e8f1f8" : "#12141a";
  try {
    this.window?.setBackgroundColor?.(bg);
    if (process.platform !== "darwin") {
      this.window?.setTitleBarOverlay?.({ color: bg, symbolColor: fg, height: 36 });
    }
  } catch (err) {
    // 老版本 Electron 或非 Windows 下没有这个能力，忽略即可
  }
});
```

注意：

- 只认 `"dark"`，其它任何值都当浅色，不要透传渲染进程给的任意颜色。
- 不要新增 `ipcMain.handle`（这是单向通知）。
- 主进程不热更，改完必须重启 `npm run start` 才看得到标题栏变化。
