## 1. 目标

1. 界面里所有由字符充当的图标，全部变成同一套 16px / 1.5px 描边 SVG。
2. 一级导航（后退/前进/刷新/收藏）视觉宽度一致，不再高低不齐。
3. 每个图标都能跟随 `currentColor` 变色（hover、disabled、选中）。
4. 保留全部 `data-i18n-title` 与 `title` 提示，不能丢 tooltip。
5. 只改图标外观，**不改任何按钮 id、onclick、行为**。

## 3. 步骤二：逐个替换（对照表）

统一写法：

```html
<button id="back" title="后退"><svg class="ic"><use href="#i-back"/></svg></button>
```

| 元素 | 位置 | 原字符 | 换成 |
|---|---|---|---|
| `#back` | L1313 | `◀` | `<svg class="ic"><use href="#i-back"/></svg>` |
| `#forward` | L1314 | `▶` | `#i-fwd` |
| `#reload` | L1315 | `⟳` | `#i-reload`（加载中由 JS 切 `#i-stop`，见 3.1） |
| `#btnStar` | L1318 | `☆` | `#i-star`，收藏后加 `.fill` 类切实心 |
| `#btnBmMenu` | L1319 | `▤` | `#i-bookmark` |
| `#btnHistory` | L1320 | `◷` | `#i-history` |
| `#btnMem` 内 `<span aria-hidden="true">☾</span>` | L1322 | `☾` | `<svg class="ic"><use href="#i-moon"/></svg>` |
| `#findPrev` | L1328 | `↑` | `#i-chev-up` |
| `#findNext` | L1329 | `↓` | `#i-chev-down` |
| `#findClose` | L1330 | `×` | `#i-close` |

### 3.1 刷新/停止、收藏星标（`renderChrome` 会覆盖 DOM）

`renderChrome()` 每次状态刷新都会改写这两个按钮的文字，只改 HTML 会被盖回去：

- L1984 `reloadEl.textContent = chromeState.isLoading ? "×" : "⟳"` → 改成设置 `innerHTML`：加载中 `#i-stop`，空闲 `#i-reload`
- L1986 `starEl.textContent = chromeState.currentBookmarked ? "★" : "☆"` → 改成 `#i-star`，收藏时给 `#btnStar` 加 `.fill`

L2011-2013 是 `#reload` 的 onclick（加载中 `stop()`，否则 `reload()`）。**不要改这段。**

### 3.2 新建标签按钮

```js
add.className = "new-tab";
add.innerHTML = '<svg class="ic"><use href="#i-plus"/></svg>';
```

并删掉 `.new-tab` 的 `font-size: 18px`。

### 3.3 标签关闭按钮

```js
x.className = "x";
x.innerHTML = '<svg class="ic"><use href="#i-close"/></svg>';
```

`.tab .x` 的 `font-size: 12px` 可删，保留 16×16 尺寸与 hover 背景。

### 3.4 休眠标签的月亮前缀

CSS 用遮罩，不要用字符：

}

### 3.5 折叠箭头的 `›`

### 3.6 图标按钮尺寸对齐

`.nav button, .icon-btn` 当前是 32×28、字号 14。改成：

```css
.nav button, .icon-btn {
  width: 30px; height: 28px;
  display: inline-flex; align-items: center; justify-content: center;
  border-radius: var(--r-8);
  background: transparent;
  color: var(--text);
  font-size: 0;            /* 防止残留字符撑宽 */
}
```

## 4. 红线

- **不许改任何 `id`、`onclick`、`addEventListener` 的行为语义。**
- 不许删 `data-i18n-title` / `title`（提示文案必须还在）。
- 不许引入外部图标库、字体图标、CDN。
- 不许改 `src/main/**`。
- 不许把图标做成 20px 或 24px——统一 16px，视觉重量靠描边而不是尺寸。
- 不许在按钮里同时放 SVG 和原字符（会重影）。
