## 1. 用户气泡加浅底（行动 #19）

**文件**：`d:\download\sparo上架应用商店版\src\renderer\shell.html` L744

**现状**：

```css
.chat-log .bubble.me { color: var(--muted); }
```

用户消息和 Sparo 消息只靠颜色区分，长对话里回溯很吃力。

**改法**：在 `.bubble.me` 上补底色与内边距，`.sparo` 保持纯文字：

```css
.chat-log .bubble.me {
  color: var(--text);
  background: var(--surface-2);
  padding: 6px 10px;
  border-radius: var(--r-10);
}
```

- 基础 `.bubble`（L735）仍然是 `padding: 0; background: transparent;`，**不要动**。
- `.bubble.me` 原来的 `color: var(--muted)` 改成 `var(--text)`，否则浅底上灰字对比度不够。
- 宽度仍由 `.bubble` 的 `max-width: 80%` 控制，不要改。

**检查**：发一条长消息 + 一条短消息，气泡不贴边、不撑破 80%、左右两侧对齐不变；暗色相关的 token 不用管。

## 2. 快捷键提示（行动 #21）

**文件**：`d:\download\sparo上架应用商店版\src\shared\i18n.ts`

只改文案，不改 HTML 的 `data-i18n-title` 属性（`applyDom()` 会自动套用）。**中英文两处都要改**，否则 `tests/i18n.test.ts` 会红。

| key | 中文 | 英文 |
|---|---|---|
| `nav.back` | `后退 (Alt+←)` | `Back (Alt+←)` |
| `nav.forward` | `前进 (Alt+→)` | `Forward (Alt+→)` |
| `nav.reload` | `刷新 (Ctrl+R)` | `Reload (Ctrl+R)` |
| `tab.new` | `新标签页 (Ctrl+T)` | `New tab (Ctrl+T)` |

**只写这四个。** 快捷键以 `src\main\browser.ts` 的 `handleChromeShortcut()`（L1189 起）为准：

- 后退 / 前进：`Alt+←/→`（L1248、L1252）
- 刷新：`Ctrl+R`（L1236）
- 新标签：`Ctrl+T`（L1196）

**没有在 `handleChromeShortcut()` 里注册的键，一律不许写进 tooltip。** 若想补 `Ctrl+W`、`Ctrl+F`、`Ctrl+L`，先在 `handleChromeShortcut()` 找到对应分支、确认生效，再决定加不加；不确定就不加。

`tab.new` 这条会被 `renderChrome` 里的 `add.title = t("tab.new")` 自动用上（L2034），无需改 JS。

## 3. 工作偏好 7 字段分组（行动 #24）

**文件**：`d:\download\sparo上架应用商店版\src\renderer\shell.html` L1700–1743（`.ds-panel[data-panel="learn"]` 里的第一个 `.block`）

**现状**：称呼、常住城市、账号、话题、口吻、口径、禁答 7 个字段平铺，读不完。

**改法**：拆成三组，字段顺序与 id **一个都不许改**：

| 组 | 字段 |
|---|---|
| 身份 | `pfNick`、`pfHome`、`pfAccounts` |
| 表达 | `pfTopics`、`pfStyle` |
| 红线 | `pfNotes`、`pfForbid` |

每组前插一行小标题：

```html
<h4 class="ds-group" data-i18n="work.groupWho">身份</h4>
```

新增三条 i18n（中英文成对）：

| key | zh | en |
|---|---|---|
| `work.groupWho` | 身份 | Identity |
| `work.groupVoice` | 表达 | Voice |
| `work.groupRules` | 红线 | Guardrails |

样式加在 `.ds-panel` 规则附近：

```css
.ds-group {
  margin: 16px 0 8px;
  font-size: 12px;
  font-weight: 600;
  color: var(--muted);
  letter-spacing: .02em;
}
.ds-group:first-of-type { margin-top: 4px; }
```

保存 / 查看 / 清空 三个按钮保持在原位置（整组末尾），不要挪到组内。
