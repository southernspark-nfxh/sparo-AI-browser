## 新边界

| 层级 | 行为 |
|---|---|
| 支付、付款、支付密码、支付验证码 | 恒拦，文案「必须用户亲自完成支付」 |
| 删除 | 放行。成功点击后侧栏提示「已删除 [目标]。若该平台有垃圾箱/撤销 API 可 7 天内恢复；否则请确认删除内容。」不调用垃圾箱 API。结果里带 `notify` |
| 逐步确认 | 保存直接做并通知。发送、发布、保存并认领、保存并发布要一次已落地确认，然后执行并通知 |
| 自动执行 | 保存、发送、发布直接做并通知。保存并认领、保存并发布仍要确认 |
| 客服发送 | 仍只填草稿 |

`gateClickText` 增加 `execMode`。不在新核心里时只拦支付。

`agent-guide.ts` 改为：删除真人数据允许执行，执行后通知用户。支付仍必须用户亲自完成。

## 没跑的真机

没有登录态，也没有另开开发版做点击。需要账号的场景：

| 场景 | 模式 | 账号 | 限制 |
|---|---|---|---|
| 保存直接完成并在侧栏看到「已保存」 | step 和 auto | 店小秘，已登录的隔离测试商品 | 可以保存这一下。不点保存并认领、不发布、不付费 |
| 发布或发送：step 先问一次，auto 直接做并通知 | 两种都要 | 头条号，已登录 | 只用测试草稿。auto 会真的发出，请指定一篇可发的测试稿 |
| 保存并认领仍要先确认 | step 和 auto | 店小秘测试商品 | 确认前必须停住。不要用正式在售商品 |
| 删除后侧栏出现恢复提示，且没有硬拦 | step 和 auto | 隔离演示页或可删的测试草稿 | 不要删正式内容 |
