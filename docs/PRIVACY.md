## 我们卖什么

Sparo 是装在你电脑上的 Windows 浏览器。软件可以只买一次、永远自备模型 Key。

**云端模型是可选服务**：登录后可走服务端代理，云端 Key 不进你的电脑。商店应用内没有支付按钮，订阅在官网管理。到期只停云端模型，网页登录和自己贴的 Key 不受影响。

## 数据存在哪

默认在这台电脑的用户目录（Windows 上为 `%APPDATA%\sparo-store`）：

- 你粘贴的 API Key 与模型设置（仅「自己的 Key」模式）  
- 若你登录云端模型：加密存放的登录令牌（Electron `safeStorage`），不含云端模型真 Key  
- 工作偏好（称呼、口径、禁答等，可选）  
- 浏览器登录态、Cookie、本地存储  

我们**没有**把网页 Cookie、自己的 Key 或工作偏好同步成「云盘」。本软件不提供把整机配置同步到另一台电脑的功能。

## 何时会离开这台电脑

- **自己的 Key：** 总结、填表、回复、发布等需要模型的功能，会把当前页相关文本发往**你配置的**模型服务（例如 DeepSeek、OpenAI 或兼容网关）。那些服务有各自的隐私政策。  
- **云端模型：** 同样的页面相关文本会发往 Sparo 的云端代理，再由代理转给模型供应商。代理用你的登录令牌识别额度，**不会把云端 Key 下发到本机**。  
- 你可以不登录、不填 Key；此时这些功能不可用。

「复制给 Agent」只把本机程序路径和本机连接方式放到剪贴板，供你粘贴给本机 Agent。

## 发送与提交

回复只写入网页输入框。填表与发帖在提交前暂停。**页面上的发送 / 提交由你点击。** 软件设计为半自动，不替你对外发出消息。

## 我们不收集的

- 不把你的 Cookie 交给云浏览器  
- 不向我们出售个人数据的业务  
- 不在本机保存云端模型的真实 Key  

可选的邮箱登录只用于云端模型额度与订阅状态。
