## 30 秒

Sparo 里攻克一件事后，人可以把**整理过的技能**发到社区，别人下载到自己的 Sparo。能搜、能点赞、能留言。

| 做 | 不做（M2 第一刀） |
|---|---|
| 发布 / 浏览 / 下载到本机 | 积分、用积分买技能 |
| 点赞、留言写体验 | 作者分成、付费上架 |
| 发布前剥掉隐私 | 后台自动上传本机经验 |
| 技能只许跑声明过的域名 | 代付款、验证码、密码类步骤 |

钱和积分以后再说。先做成 GitHub 那种分享，让社区转起来。

## 为什么现在不动

1. M1 是上线版：云端登录、点数、安装包。人测没走完不要开社区。  
2. 已经有「云端点数」买模型。再搞社区积分，两套分，人会晕。  
3. 一能买技能，就会灌水、刷赞、劣质包、恶意自动化。  
4. 本机「学到的经验」大多是「这站要先登录」——直接公开帮不了人，还暴露常去哪些站。

## 和本机学习怎么接

```
本机卡住 → 问人 → lessons.json（只留这台电脑）
                ↓ 人点「分享到社区」（可选）
         整理成可发布技能（标题、站点、做什么、步骤）
                ↓ 剥掉密码 / 验证码 / 付款 / 邮箱
         发到社区 → 别人下载进自己的 Sparo
```

- **不自动上传。** 没有「分享」这一下，经验永远在 `%APPDATA%\sparo-store`。  
- 拿去分享的是技能包，不是原始 lesson 原样贴出去。  
- 下载回来的技能，执行前仍要过人：发送、付钱、登录墙暂停。

## 产品形态（M2）

1. 侧栏或设置：「把这条整理后发布」  
2. 社区页（官网或应用内只读列表 + 外开官网）：标题、站点、作者、赞、留言  
3. 下载：写入本机 skills / lessons，标明来源  
4. 官方先放约 10 个精选（发帖 / 填表 / 常见卡住）当种子  
5. 服务仍挂 `sparo-pay` 旁的独立路由（如 `/skills`），**不要**并进 AI 异世界

## 闸门（必须先于开放 UGC）

- 打包格式：`declared_domains` + `declared_actions`；缺了不让发、不让跑  
- 域名用标准 URL 解析，防 `evil-ctrip.com`  
- 自动拒：裸 IP、短链跳转、支付自动化、要验证码内容、带密码字段  
- 发布预览给作者看一遍将发出去的步骤  
- 恶意包：下架，本机已下载的标「已失效」

## 以后再说（M2.5 / M3，未立项）

- 社区积分、用积分买技能、作者分成  
- Gumroad / 商店内购技能  
- 匿名同步本机全部经验  
- 和云端模型点数互通

## 开工条件（缺一不要开）

- [ ] M1 人测过：登录 10 点、一句话任务只计 1 次、用尽去官网、断网退回自己的 Key  
- [ ] 本机学习 Phase 1 能稳定：卡住会问、经验能删  
- [x] 有可发布的技能打包格式（先本地： [SKILL-FORMAT.md](./SKILL-FORMAT.md) + `strategies/skills/`；联网社区仍未开）  
- [ ] 本文闸门有对应测试，恶意样本能被拒

## 验收（到 M2 才勾）

1. 本机一条经验 → 人点分享 → 社区能搜到（无密码/验证码）  
2. 另一台机器下载后能跑，且只在声明域名上跑  
3. 点赞、留言可用  
4. 未声明域名 / 支付类步骤 100% 被拒  
5. 全库搜不到「积分购买技能」入口
