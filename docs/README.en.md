# Sparo

An AI browser for Windows that works on the page you're looking at. Drafts go into the input box. Before anything sends, it stops and waits for you.

Free with your own API key — DeepSeek, OpenAI, or a compatible endpoint. Rather not manage keys? Sign in for cloud models; those keys stay on our servers, never on your PC.

Four jobs: summarize the page · fill forms · draft replies · publish.
