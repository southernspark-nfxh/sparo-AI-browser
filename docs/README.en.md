# Sparo

**The AI browser that acts.** Open a page. AI fills, replies, and posts. You confirm before send.

Store listing copy (Microsoft Store zh/en, itch.io, preflight): [listings/README.md](./listings/README.md)  
Privacy: [PRIVACY.en.md](./PRIVACY.en.md)  
Product (Chinese source of truth): [PRODUCT.md](./PRODUCT.md)

You buy the app. Paste your own API key. No membership. Replies are drafts; you click send on the page.

## Language

Settings → Language → **English** (remembered). On an English Windows install with no saved choice, the UI follows the OS.

Jobs: Summarize · Fill form · Reply · Publish. Button: **Let it act**.

## Files

- `Sparo-Setup.exe` — installer  
- `Sparo-Portable.exe` — portable
