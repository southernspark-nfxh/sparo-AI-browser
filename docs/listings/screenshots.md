# Screenshots · 截图说明

微软：每语言至少 1 张，建议 4 张。PNG，桌面 **1366×768 或更大**（可用 1920×1080），&lt; 50 MB。不要把商店 Logo、年龄分级标、别的平台按钮画进图里。

itch：同样四张即可；另做一张封面 **630×500**。

## 英文界面（en-US / itch）

设置 → Language → English，必要时重启窗口确认侧栏已是英文。

| 文件名 | 画面 |
|---|---|
| `ms-en-01-chat.png` | 已打开普通网页；右侧 Chat、四个动作 Summarize / Fill form / Reply / Publish、按钮 Let it act |
| `ms-en-02-settings.png` | Settings 抽屉：Brand / Key，可见 Bring your own key，不是会员页 |
| `ms-en-03-draft.png` | 聊天或评论页；输入框里已有草稿；页面上的 Send 仍在，未替用户点 |
| `ms-en-04-agent.png` | Settings 里 Copy for Agent 一段 |

封面 itch：`itch-cover-630x500.png` — 窗口缩略 + 一句 *The AI browser that acts*。

## 中文界面（zh-CN）

Language → 中文。对应 `ms-zh-01` … `ms-zh-04`。画面与上表相同，文案为总结 / 填表 / 回复 / 发布 / 让它动手。

## 不要拍

- 指纹多开、店小蜜、原版 Sparo  
- 未打码的真实客户对话、密钥全文  
- 全自动发送成功的假画面
