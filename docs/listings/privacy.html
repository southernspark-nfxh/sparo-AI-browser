Sparo Privacy Notice

Effective: 2026-08-30. Product: Sparo (Windows store edition).

What we sell

Sparo is a Windows browser that runs on your PC. We sell the software. No membership. We do not bill model usage. No cloud account.

Where data lives

On this PC, under your user profile (Windows: %APPDATA%\sparo-store): API keys and model settings you paste; optional work prefs; browser logins, cookies, and local storage; optional recorded actions.

We do not sync that data to a Sparo cloud.

When data leaves this PC

If you use Summarize, Fill form, Reply, Publish, or chat that calls a model, relevant page text is sent to the model host you configured (DeepSeek, OpenAI, or a compatible gateway). Those hosts have their own policies. If you never paste a key, those features do not run.

Copy for Agent puts the local app path and local connection details on the clipboard for you to paste into a local agent.

Send and submit

Replies are written into the page input. Forms and posts pause before submit. You click Send or Submit on the page. The product is semi-automatic; it is not designed to send on your behalf.

What we do not collect

No Sparo cloud login. We do not hand your cookies to a cloud browser. We do not sell personal data.

Children

Built for work and personal productivity, not for children under 13.

Contact

Use the support email on the store listing or developer account.

Sparo 隐私说明

生效：2026-08-30。商店版产品名：Sparo。

我们卖什么

Sparo 是装在你电脑上的 Windows 浏览器。只卖软件，不卖会员，不代扣模型费用，不设云端账号。

数据存在哪

默认在这台电脑的用户目录（%APPDATA%\sparo-store）：你粘贴的 API Key 与模型设置；可选工作偏好；浏览器登录态、Cookie、本地存储；可选录下的操作。

没有把上述内容同步到 Sparo 自己的服务器。

何时会离开这台电脑

当你使用需要模型的功能时，当前页的相关文本会发往你配置的模型服务。那些服务有各自的隐私政策。不填 Key 则这些功能不可用。

「复制给 Agent」只把本机程序路径和本机连接方式放到剪贴板。

发送与提交

回复只写入网页输入框。填表与发帖在提交前暂停。页面上的发送 / 提交由你点击。

我们不收集的

不以 Sparo 云账号登录；不把 Cookie 交给云浏览器；不向我们出售个人数据。

儿童

面向职场与个人生产力，不面向 13 岁以下儿童。

联系

以商店列表里的支持邮箱 / 开发者帐户为准。
