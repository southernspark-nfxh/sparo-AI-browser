## Generative AI disclosure (itch form)

itch asks whether the **project** uses generative AI.

Accurate answers:

- The **Windows app is human-written software**, not a dump of AI-generated game assets.  
- **In use**, Sparo may call a **third-party LLM** (DeepSeek, OpenAI, or a compatible host) **only if the user pastes their own API key**. Page text they choose to process is sent to that provider, not to us.  
- Drafted replies are **not auto-sent**.

Suggested checkbox wording if the form is binary:

> This tool can call third-party generative AI when the user provides an API key. The downloadable app itself is not an AI-generated asset pack.

Do **not** tick “this game’s art/audio was generated by AI” unless you actually shipped generated art.

## Description (long, Markdown)

itch long description supports Markdown. Use `##` (Header 2), not a single `#`.

```markdown
## The AI browser that acts

Other AIs stop at the chat box. You still copy the answer back into Chrome to fill a form, reply, or publish. Sparo works on the **page you are watching**. Your login stays on this PC. You confirm before send.

## Four jobs

- **Summarize** this page
- **Fill form** — stops before submit
- **Reply** — draft into the box; you click send
- **Publish** — pauses before submit

## Your key, not a membership

You buy the app. Model usage bills the API account you paste: DeepSeek, OpenAI, or an OpenAI-compatible host (Qwen, Kimi, GLM, OpenRouter, Groq, local Ollama, …). Native Anthropic / Gemini protocols are not this path.

## Optional: your coding agent

Settings → **Copy for Agent**. Cursor, Claude, or any local agent can drive the same window. Installer and portable builds copy the real executable path.

## Not in this build

No persona farms, no fingerprint multi-boxing, no unattended auto-send.
```
