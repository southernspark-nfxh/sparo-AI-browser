# 三通道设计稿（门岗 / 三通道 / 终审）

> 状态：**设计稿，未开工**。先评审后动代码；落地按 §6 分期，每期独立 commit；脑区（门岗查表、通道选择、登记/摘除）与非脑区（存储、UI、工具层）不混提交。  
> 背景：脑手分离根因排查（决策点无登记、fallback 无过期、脑区提交无隔离、无模型优先热修通道）。那四机制管「代码怎么改」，本稿管「任务怎么流」，配套生效。  
> 先读：[ARCHITECTURE.md](./ARCHITECTURE.md) · [SKILL-FORMAT.md](./SKILL-FORMAT.md) · [AI-LEARNING.md](./AI-LEARNING.md) · [PRODUCT-TASKBOOK.md](./PRODUCT-TASKBOOK.md)

## 0. 一句话

大模型是脑：分流、选择、规划、登记提议都由模型拍板。  
本地代码只做两件事：**门岗查表**（完整原话精确匹配）、**终审兜底**（人闸 + 契约）。  
凡是「像不像、算不算、该不该」的判断，一律归脑，本地禁止抢答。

## 1. 总图

```text
用户原话
  │
  ▼
门岗（本地查表：完整原话精确匹配，零语义判断，不调模型）
  │ 命中                            │ 未中
  ▼                                 ▼
无意识通道                        大脑（understand 分类）
（直接回放技能）                    │ 已知模式                │ 未覆盖
  │                                ▼                      ▼
  │                             有意识通道              新任务通道
  │                             （模型选技能/流水线）   （现场规划 → 计划卡人确认）
  │                                │                      │
  ▼                                ▼                      ▼
  └────────────────── 终审（人闸：登录/验证码/付钱/发送；契约验收）──────────────────┘
                                     │
              有意识成功（一步到位的技能）→ 用户沉默即登记触发语（→ 无意识）
              新任务成功 → 沉淀四件套技能草稿（→ 有意识）
              无意识连败 → 摘除触发语（→ 回退有意识）
```

## 2. 三条通道

### 2.1 门岗（本地，不调模型）

- 输入：用户原话；只做**表面清理**：去首尾空白、合并连续空白、全角→半角、去句末标点。禁止同义词、语序变换、槽位通配等任何语义归一。
- 查表：完整原话精确匹配 `skill-triggers.json`。命中 → 无意识通道；未中 → 大脑。
- 不调模型、零网络：用户没配模型时门岗照常工作。
- 门岗只回答「这句原话登记过没有」，不回答「这句话像什么」。

### 2.2 无意识通道（直放）

- 触发：门岗命中。
- **只接一步到位的任务**（单步固定手：打开结果页、读这一页、一句翻译等）。多步骤技能永不进门岗查表——比价、调研、出差这类必须大脑参与，走有意识通道拿 skill 当脚手架，不做逐字直放。
- 行为：直接 `run_skill` 回放固定步骤，不经 understand/reasoner 逐步推理。
- 侧栏只说一句「按惯例：<技能名>」+ 可中断。
- **无意识 ≠ 免检**：仍过终审与 human_gates；失败不硬撑，转交大脑（同一句话走有意识通道续跑）。
- **P0 降级**：不动脑期间做不到当轮转脑——失败只记账，`fails>=2` 停用触发语后**不再零 LLM 直放**；原话若仍是「运行妙招」句式，下一句走窄路（`runSkillTool` 正常路径），不进工作单；当轮转脑留给 P2。回放直接 `runSkill`，不走 `runSkillTool`（后者有 readings 时会调 LLM 写摘录，回放必须零 LLM 请求）。P0 人闸以 runner 现状为准（runner 不读 `human_gates`，读到登录页正文算成功），本期不补。

### 2.3 有意识通道（大脑分流到已知模式）

- 触发：门岗未中，大脑判断属于已知模式（有技能 / 有流水线覆盖）。
- 行为：现有 kernel 流水线（understand → runtime → reasoner → verify）。模型抽参数、选技能、填槽；本地只校验合法 cap / 槽 / 站点，不替模型选。
- `match_skill` 保留为大脑的候选查询工具；`run_skill` 里的模糊兜底（按 query 猜技能直接跑）**改为只接受 id 或已登记触发语**，猜不中把候选返回模型重选——本地不据此自动执行。
- 成功 → 进入登记评估（§3）。

### 2.4 新任务通道（创新兜底）

- 触发：大脑判断未覆盖（无技能、无流水线、置信度低）。
- 行为：模型现场编计划 → 计划卡给人确认 → 执行。未覆盖任务不闷头跑。
- 成功 → 沉淀为新技能草稿，用户沉默即采纳。沉淀物是**四件套**（见 §3），不是动作录像：大脑回看 `mission-journal` 执行日志，压缩成路线 / 槽位 / 坑表 / 验收。

### 2.5 技能的复用与进化（有意识通道内）

- 同类任务再来：大脑读 skill 当脚手架——步骤不用现想、入口 URL 现成、坑提前知道、验收现成。每一步具体怎么点，大脑看页面现定。
- 每跑一次更新成败计数；坑表遇到一条加一条。
- 大脑某步偏离路线还跑成了，同一偏离攒够 2 次 → 提议改路线（用户沉默即采纳）。
- 点击坐标 / 选择器级的动作录像不沉淀：网站一改全废，是负资产。

### 2.6 终审（全通道共用，不可绕过）

- 人闸：登录、验证码、付钱、发送 → `waiting_human`，等人点。
- 契约：交付物齐了才合成手册；调研类必须出报告页并在窗口打开（沿用死规则）。
- 三条通道同一套终审，无意识通道不例外。

### 2.7 通道间流转（动态成长）

- 新任务 →（沉淀技能四件套）→ 有意识 →（仅一步到位的技能登记触发语）→ 无意识。
- 无意识连败 → 摘除触发语 → 回退有意识。
- 「熟练度」只由真实执行结果驱动，不由规则预设档位。

## 3. 数据结构

`%APPDATA%\sparo-store\skill-triggers.json`（**独立文件**，不写进种子包 `strategies/skills/*.json`——`seedBundledSkills` 升级会覆盖种子文件，触发语放里面会被刷掉）：

```json
{
  "triggers": [
    {
      "id": "8位hex",
      "skillId": "taught-xxx",
      "text": "今天北京天气怎么样",
      "addedAt": "…",
      "runs": 0,
      "fails": 0,
      "enabled": true,
      "lastUsedAt": "…"
    }
  ]
}
```

扁平数组（不按技能 id 做 key）：按 id 删/停更直接；同一 normalize 文本只留一条。

- `text`：登记时的完整原话（normalize 后存储与比对）。
- **只登记一步到位的技能**：多步骤技能不进门岗查表，复用靠有意识通道读 skill 脚手架。
- 命中跑失败 → `fails+1`；连续 2 次失败自动 `enabled=false`，回退大脑，设置页可恢复/删除。
- 官方种子包 `triggers` 恒为空——出厂不带任何触发语，全部来自本机验证。
- 设置「经验」面板沿用 lessons 的位置管理触发语（查看/停用/恢复/删除）。
- 触发语不上云、不进技能社区分享包（M2 另议）。
- 与 `lessons.json` 的关系：lessons 是**站点级**经验（host + trigger + advice），触发语是**任务级**经验（原话 → 技能）。两套并存，互不代替。

## 3.1 沉淀技能四件套（多步骤工作经验）

复用 `strategies/skills/*.json` 格式（[SKILL-FORMAT.md](./SKILL-FORMAT.md)），`source: "taught"` + `distilled: true` 标记为沉淀技能。**沉淀的是路线不是动作录像**：

```json
{
  "id": "taught-compare-shop-x",
  "source": "taught",
  "distilled": true,
  "route": [
    { "kind": "fixed",  "tool": "navigate", "args": { "url": "https://search.jd.com/s?keyword={{queryEnc}}" } },
    { "kind": "open",   "goal": "读列表前 N 条，不点详情", "tools": ["page_text"] },
    { "kind": "fixed",  "tool": "navigate", "args": { "url": "https://s.taobao.com/search?q={{queryEnc}}" } },
    { "kind": "open",   "goal": "同上读列表，汇总写报告页", "tools": ["page_text", "report"] }
  ],
  "params": { "query": { "type": "string", "required": true } },
  "pitfalls": [
    { "milestone": 1, "note": "京东列表先关弹层", "from": "2026-10-23 运行" },
    { "milestone": 3, "note": "淘宝跳登录就换备用站", "from": "2026-10-23 运行" }
  ],
  "contract": { "minOffers": 3, "fields": ["title", "price", "link"], "deliverable": "report" },
  "stats": { "runs": 4, "success": 3, "fail": 1 }
}
```

- `route` 里程碑两种手：`fixed`（稳定 URL / 动作模板，参数用槽位）与 `open`（只写目标，大脑现场看页面决定怎么点）。
- `pitfalls` 挂在里程碑上；与 `lessons.json` 同源——站点级坑同时进 lessons，跑这条 skill 时随里程碑带出。
- `contract` 交给现有 `verifyContracts` 验收。
- 每跑更新 `stats`；同一偏离攒够 2 次 → 提议改 route（大脑提议 + 用户沉默采纳）。

## 4. 决策点登记（衔接四机制）

| 决策点 | 谁拍板 | 本地可否抢答 |
|---|---|---|
| 门岗命中 | 查表（完整原话精确匹配） | 仅查表 |
| 通道选择（有意识 / 新任务） | 大脑 | 禁止 |
| 技能选择与参数抽取 | 大脑 | `match_skill` 只出候选 |
| 触发语登记 | 大脑提议 + 用户沉默确认 | 禁止自动登记 |
| 触发语摘除（连败 2 次） | 本地规则 | **已登记，过期 2027-01-23** |
| normalize 规则集 | 本地规则 | **已登记，过期 2027-01-23** |
| `run_skill` 模糊兜底 | 移除（改为返回候选） | 禁止 |
| 参数化触发语 | **已拍板：不做**（2026-10-23，方案A 逐字原话） | 禁止 |
| 技能可否登记触发语（是否一步到位） | P0 本地白名单（≤3 步 + 白名单动作 + 无 `{{` 槽 + 无 required 参数），已登记，**过期 2027-01-23**；P2 起大脑判定，白名单删除 | P2 前允许本地白名单，其余禁止 |
| 路线修订（同一偏离攒 2 次） | 大脑提议 + 用户沉默采纳 | 禁止自动改写 |
| 「运行妙招」句式窄路（确定性进 run_skill，不进工作单/大脑） | P0 本地正则（登记入口确定性需要；stub.ts 88–90 已有同句式，此处只是确定性化），已登记，**过期 2027-01-23**；P2 随大脑接管一并评估是否保留 | P0 允许，其余句式禁止仿效 |

## 6. 分期落地（每期独立 commit；脑区与非脑区不混提交）

- **P0 门岗**：normalize + 精确查表 + 登记/摘除 + 设置页管理。不动大脑通道。
- **P1 候选化**：`run_skill` 移除模糊直跑；`match_skill` 候选进 understand/reasoner 上下文。
- **P2 沉淀**：新任务计划卡确认 + 成功后压缩 journal 成四件套草稿（route / params / pitfalls / contract）。
- ~~P3 参数化触发语~~：已拍板不做（方案A），此项关闭。

## 7. 验收 QA

- 登记过的原话一字不差 → 直放执行；改一个字 → 走大脑。
- 未登记原话永不被门岗吞掉。
- 多步骤技能（比价、调研、出差等）不进无意识通道，回回走大脑。
- 触发语连续 2 次失败 → 自动停用并出现在设置页。
- 未配模型：门岗照常直放；新任务通道进 `waiting_human` 等人。
- 三条通道过同一套人闸与契约验收。
- 商店版构建不出现价格/支付 UI；触发语不出本机。
- `npm test` + `npm run typecheck` 全绿。

## 8. 禁区

- 门岗禁止关键词 / 子串 / 模糊 / 语义匹配；normalize 禁止语义归一。
- 本地禁止替大脑做通道选择、技能选择。
- 触发语禁止上云、禁止默认进技能分享包。
- 不存密码、验证码、带 token 的 URL（沿用 [AI-LEARNING.md](./AI-LEARNING.md)）。
- 热修先走模型 / 提示词通道；确需本地规则必须登记 + 标过期。
