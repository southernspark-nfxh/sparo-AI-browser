## 商店长介绍（可直接贴）

Sparo 是会动手的 AI 浏览器。

别人家的 AI 把答案停在对话框里，填表、回客服、发帖还得你自己抄回 Chrome。Sparo 反过来：它动的就是你眼前这一页。登录还是你的登录，窗口还是你的窗口。

四个日常动作：

- **总结**这一页  
- **填表**（提交前停下）  
- **回复**客服或评论（只填草稿，你点发送）  
- **发布**内容（提交前暂停）  

它不替你点发送，也不把账号交给云浏览器。模型费用走你自己的 API Key：DeepSeek、OpenAI，以及通义、Kimi、智谱、OpenRouter、Groq、本机 Ollama 等 OpenAI 兼容接口。

已经有 Cursor 或 Claude 的人，可以用「复制给 Agent」让同一个窗口给本地 Agent 当手。没装那些软件也可以：人在侧栏说话， Sparo 一样动手。

不做什么：不做人设矩阵、不做指纹多开、不承诺无人值守全自动发帖。

## 功能要点（商店勾选 / 项目符号）

- 人机同窗：AI 操作当前页，你看得见、停得下  
- 总结 / 填表 / 回复 / 发布  
- 发送前确认，半自动客服与发帖  
- 自备 API Key，不卖会员  
- 国内与海外常见 OpenAI 兼容网关  
- 界面语言：中英日韩西葡德法意  
- 本机保存登录与偏好；安装包与便携版

## 和 Chrome 一句话（媒体可用）

Chrome 是你自己点的浏览器。Sparo 还是浏览器，多了一只你看着的手：它填完，发送前问你。

## 隐私与分级提示

- 无账号系统、无云同步会员  
- 密钥与 Cookie 仅本机  
- 不自动对外发送用户内容（发送由用户在网页上确认）  
- 适合工作生产力分类；不要标成无人值守营销机器人
