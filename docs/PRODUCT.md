# Sparo · 会动手的 AI 浏览器

**打开网页，AI 帮你填、帮你回、帮你发。发送前你确认。**

Sparo 是装在你电脑上的浏览器：你看见的窗口，就是 AI 动手的那一扇窗。登录还是你的登录，页面还是你正在看的页面。它是手，不是另一个云端替身。

免费永远自备 Key。订阅是可选的云端模型：密钥只在服务端，不进你的电脑。微软商店里只出现登录 / 去官网管理订阅，没有支付按钮。

---

## 最大卖点

别人家的 AI **会说不会做**：答案停在对话框里，填表、回客服、发帖还得你自己切回网页敲。

Sparo 反过来：**AI 在你眼前的网页上动手**，你看着、你能停下、发送前你点头。

| 卖点 | 用户得到什么 |
|---|---|
| **人机同窗** | AI 点的、填的，就是你正在看的这一页。不用把登录交给云浏览器，也不用两套窗口来回复制。 |
| **四件实事** | **总结**这一页、**填表**、**回复**客服/评论、**发布**内容。不是泛泛「聊天」。 |
| **一句话说完日常事** | 出差、订酒店/机票、买前比价、调研笔记、挂号、租房：打开结果页，汇成手册。付钱、投递、发送仍是你点。 |
| **发送前你确认** | 回复只写进输入框，发帖在提交前暂停。它不替你点发送，高风险动作你说了算。 |
| **你的 Agent 也能开这扇窗** | 点一次「复制给 Agent」，路径和连接方式一起带走。Cursor、Claude、或任何能接本地工具的 Agent，操纵的都是同一窗口。 |
| **装上就能用** | 双击安装包或便携版。复制出去的是你双击打开的那个程序，不是内部文件。开发调试和装好之后同一套说法。 |
| **数据在这台电脑** | 网页登录、偏好、自己的 Key 写在本机。可选云账号只换 JWT，云端模型的 Key 不进电脑，也不把 Cookie 交出去。 |

一句话记：

> 聊天 AI 只能告诉你怎么填；Sparo 在你看着的网页上填完，发送前问你。

## 解决的痛点

| 痛点 | 常见现状 | Sparo |
|---|---|---|
| AI 和网页是两张皮 | 左边 ChatGPT 给文案，右边 Chrome 还得手抄 | 同一窗口：它填、你看 |
| 云浏览器要重新登录 | 把账号交给远端机器，或再扫一次码 | 用你已经登好的站 |
| 自动化发了才发现写错 | RPA / 全自动客服直接点发送 | 半自动：草稿进框，人点发送 |
| 给 Agent 接浏览器像装服务器 | 端口、Token、配置文件、路径对不上安装包 | 一个按钮复制；安装包和便携版都是真实程序位置 |
| 填表要逐字敲、发帖循环失败 | 脚本对着输入框一个字一个字打 | 整段写入；发帖走站点步骤，提交前停 |
| 软件靠会员卡额度 | 月费套餐、云端 Key 绑死本机 | 免费永远自备 Key；订阅只是可选的云端模型，Key 不进电脑 |
| 「已连接某某」其实没装 | 大按钮假装连上 Cursor / Claude | 没装就不出现写入；有装才给快捷方式 |

不解决、也不假装解决的：

- 不替你运营店铺、不做人设矩阵、不做指纹多开（那是原版 Sparo 的线）
- 不承诺全自动无人值守发帖 / 下单
- 不把云端模型 Key 下发到你电脑；自己贴的 Key 也只留在本机

## 给谁

职场里每天要在网页上**读、填、回、发**的人：客服、运营、行政、需要把资料填进各种后台的人。

也给已经有 Cursor / Claude / 自建 Agent 的人：他们缺的不是又一个聊天框，而是**能开你正在看的浏览器的手**。

## 和传统浏览器比

Chrome / Edge / Safari 是**人自己点、自己填**的浏览器。 Sparo 还是浏览器，多了一只你看着的手。

| | Chrome / Edge 等 | Sparo |
|---|---|---|
| 打开网页、登录、收藏 | 有 | 有（你的登录留在这台电脑） |
| AI 写文案 | 另开 ChatGPT / 复制粘贴 | 同一窗口：它写进你正在看的框 |
| 填表、回客服、发帖 | 人逐项敲 | 四个动作：总结 / 填表 / 回复 / 发布 |
| 订票、比价、调研、办事 | 自己点城市、日期、搜索框 | 一句话打开结果页，侧栏出手册；重站不硬闯 |
| 发送 / 提交 | 人点 | **仍是人点**。AI 只填草稿，提交前暂停 |
| 模型怎么付 | 各家网页自己的会员 | **免费自备 Key**；也可登录用可选的云端模型（Key 不进电脑） |
| 数据去哪 | 看那家云服务 | 自己的 Key、网页登录、偏好写在本机 `%APPDATA%\sparo-store`；云端 JWT 本机加密存放 |

不是「比 Chrome 更快的上网」。是：**网页还在，AI 动手，发送前你确认。**

和对话框 AI 的差别见上文「最大卖点」。模型怎么配（国内 / 海外 / 本机）：[API-KEYS.md](./API-KEYS.md)。上架商店短介绍：[STORE-LISTING.md](./STORE-LISTING.md)。按字段粘贴（微软 / itch）：[listings/README.md](./listings/README.md)。隐私政策：[PRIVACY.md](./PRIVACY.md)。

## 人怎么用

1. 双击 `Sparo-Setup.exe` 或 `Sparo-Portable.exe`，打开 Sparo。
2. 在侧栏 **设置** 二选一：贴自己的模型 Key（DeepSeek / OpenAI，或兼容接口），或登录体验云端模型（每台设备 3 次，密钥不进电脑）。自己的 Key：[API-KEYS.md](./API-KEYS.md)。
3. 打开要处理的网页。
4. 用侧栏四个动作，或直接在对话里说目标：

| 动作 | 做什么 | 你还要做什么 |
|---|---|---|
| 总结 | 读当前页，写出要点 | 看结果 |
| 填表 | 识别字段，按你给的资料填 | 提交前它停下 |
| 回复 | 扫描会话，起草并填进输入框 | **你点页面上的发送** |
| 发布 | 按当前站走发布步骤 | **提交前暂停，你确认** |

侧栏也可以直接说目标，不必先点四个按钮：

| 你说 | 窗口做什么 | 你还要做什么 |
|---|---|---|
| 在携程查 9 月 15 日伊斯坦布尔的酒店 | 打开酒店列表，手册里带店名和详情链接 | 人选房、付钱 |
| 北京到曼谷 9 月 16 日出发 22 日回来，含酒店和机票 | 拆去程 / 酒店 / 回程，出行程手册 | 人选班次、付钱 |
| 戴森吹风机 在淘宝和京东比价 | 打开检索对比，不进会卡死的商城首页 | 人点链接下单 |
| RAG 是什么，做成笔记 | 打开检索和百科，出调研笔记 | 你阅读 |
| 帮我回一下评论 | 草稿填进输入框 | **你点发送** |

暂停 / 待确认一直在侧栏。它动手时你看得到。界面语言可在侧栏切换（中英日韩西葡德法意），选择会记住。

## Agent 怎么接（卖点要能兑现）

不要让用户去找端口和配置文件。

1. Sparo **保持开着**。
2. 点 **复制给 Agent**（只有这一个按钮：程序位置 + 连接方式）。
3. 把剪贴板发给你的 Agent，或贴进它的本地 MCP / 工具配置。
4. 对本机的 Cursor / Claude：只有检测到真的安装了，才会出现「写入」。没装不会假装已连接。

安装包、便携版、开发运行，复制出来的都是**你双击打开的那个程序**。Agent 连上之后先调用 `sparo_info`，再按技能做事（填表不要循环单字填写；客服不要代点发送）。

详细步骤：[AGENTS.md](./AGENTS.md) · 填表：[UNIVERSAL-ANALYZER.md](./UNIVERSAL-ANALYZER.md) · 发布：[PUBLISHING.md](./PUBLISHING.md) · 客服：[CUSTOMER-SERVICE.md](./CUSTOMER-SERVICE.md)
