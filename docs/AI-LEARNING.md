## 四段（浏览器版）

```
同一按钮连点 3 次 / 点了 URL·标题都没变 / 跳到登录页 / 验证码墙
        ↓
侧栏问一句具体的（是/否，或：有弹窗 / 要换入口 / 先登录 / 先不管）
        ↓
人答完 → 写成规则，只留本机
        ↓
下次同站：先关弹窗，或停下来等人登录 / 过验证
```

## 规则长什么样

```json
{
  "id": "…",
  "host": "ctrip.com",
  "trigger": "login",
  "advice": "pause",
  "note": "要先登录",
  "applyCount": 0
}
```

`trigger`：`login` | `overlay` | `captcha_human` | `dead_click`  
`advice`：`pause` | `dismiss_overlay` | `stop_retry` | `wait_human`

禁止写入：密码、邮箱、验证码、带 token 的完整 URL、页面 HTML。
