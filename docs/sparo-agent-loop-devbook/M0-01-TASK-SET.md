- 过去的 mission id 只作历史索引。复跑产生新 id，不要求对上旧 id。
- 旅行日期在执行当天换成当时可订的未来日期，并在当次记录里写下实际发出的整句。比较底账时用这句实际原句，不拿过期日期硬比。

## G1–G8

### G1 打开微博

- 原句：`打开微博`
- 前置：任意页
- 现行底账：`close.reason=done`；助手句为 `已打开 weibo.com。`；计划只有 1 步且 `cap=navigate`。人已经在微博上时，这一步可以是 `skipped`，笔记写当前页已在该站。
- v2 期望：轻量路径。一个真实 navigate 或合法 skipped。无独立 Verifier 调用。

### G2 近三天微博做成文档

- 原句：`当前我打开的这个博主 最近三天的微博 帮我复制下来 做成一个文档`
- 前置：已经停在 `weibo.com/u/2803301701`
- 现行底账：`realSteps>=1`；第一条有 findings 的步骤 `cap=read_page`；有助手句含 `正在做 1/`。缺交付时现行链路可以 `incomplete`，助手句要同时含「还缺」和没执行的计划步。禁止 `done` 且 `realSteps=0`。
- v2 期望：文档是独立交付。缺步不得 `done`；不能继续时转 `blocked`。只有用户明确按现状结束才记 `incomplete`。

### G3 阅读页之后说采集

- 原句：`把最近 3 天微博逐条复制下来`
- 前置：上一条助手消息带阅读页，`doc.kind=read`
- 现行底账：新出现一条 `op=open` 和新的 `mission.id`。不把上一份阅读页改个标题当完成。
- v2 期望：模型判新任务。新思路卡，采集交付，不改旧标题。

### G4 博主画像

- 原句：`研究博主 人民日报 画像，最好上百条`
- 前置：任意
- 现行底账：这句只有一个没被 `close.reason=dup` 掉的有效单。采集步能看到滚动或翻页。`reports\` 在开单之后有新文件，正文写实际样本量。
- v2 期望：计划含 `research_mission`。无真实采集不得 `done`。样本量与证据条数一致。

### G5 挂起后短肯定

- 原句：单独一句 `打开`，或 `好`，或 `继续`。三条都保留，复跑时记清用的是哪句。
- 前置：一张 `waiting_human` 的单，侧栏问过要不要打开或换入口
- 现行底账：不新开 `op=open`。原 id 上继续有 `turn`。这句之后不立刻 `close`。
- v2 期望：同 id 恢复。墙没解除不得立刻 `done`。带宾语的「打开微博」不走这条。

### G6 纯创作

- 原句：`帮我写一首诗`
- 前置：任意
- 现行底账：用户这句话之后有助手回复。先出思路或确认，不把整首诗直接贴进侧栏就算完成。
- v2 期望：这首诗若落成文档，走完整路径和独立验收。确认前没有工具副作用。无浏览器任务时不得虚构网页证据。

### G7 打开后再搜索

- 原句：`打开百度，搜今天北京天气`
- 前置：任意
- 现行底账：`realSteps>=1`，其中有 `search_read` 或等价搜索发现。助手句不是只有 `已打开 baidu.com。`
- v2 期望：只开站不能通过验收。答案绑定搜索结果。

### G8 长采集滚动

- 原句：不单列。在 G2、G4 或 R1 跑到无限滚动页时一起看。
- 前置：无限滚动页
- 现行底账：第二次及以后的 `page_text` 含 `较上次 +` 或 `较上次 -`。出现 `较上次 +0 字` 之后，下一次工具指纹不是上一次原样再来。
- v2 期望：观察里有真实增量或等价字段。`+0` 后换策略，并说明实际上限。

## 三条代表任务

### R1 调研

- 原句：`帮我对比三款 小米15、iPhone 16、华为Mate 70 哪个值得买`
- 来源：历史实际原句，样本 `m-mvqd6bpj-27mxu`。S10 模板是「三款 XX 手机」。早先改写成没有「三款」和空格的句子，与这条底账对不上，不再使用。
- 前置：任意
- 现行底账：窗口打开新报告页。对照内容在报告里。侧栏只有一句加卡片，不把对照表堆进聊天。
- v2 期望：完整路径。`research_mission` 真实执行，报告打开。漏来源、漏交付、漏计划步不得 `done`。

### T1 旅行

- 模板：`帮我搜一下 {入住日}和{离店日}南京的酒店 {去程日}北京到南京高铁时间和价格 {返程日}晚返回北京`
- 冻结关系：词序与 S7 相同。去程日是入住日前一天，离店日与返程日是同一天。2026-10-27 用过的一组是酒店 11 月 7–8 日、去程 11 月 6 日、返程 11 月 8 日晚，只作历史，复跑必须换新日期。
- 前置：任意
- 现行底账：酒店、去程、返程三段都有对应发现，或关单说明还缺哪一段。去程日期不得被换成酒店入住日。
- v2 期望：`trip_plan` 是计划中的必跑步。三段证据逐段对账，一条去程发现不能抵返程。

### P1 发布

- 原句：`帮我写一条今天热搜相关的微博`
- 来源：S3 的历史原句，见 `docs/BUG-20261027-WEIBO-SKILL-MISS.md` 与 `docs/BUG-20261027-S3-READING-PAGE-DONE.md`。批次模板里的「XX（当下热点）」不另造新句。只测草稿，不测 S4 的公开发送。
- 前置：任意，且未授权自动发送
- 现行底账：可以查热点并填写草稿。没有发送动作。发布框没有被自动点发送。
- v2 期望：外部写操作走完整验收。未授权不得发送。草稿存在不等于已发送。
