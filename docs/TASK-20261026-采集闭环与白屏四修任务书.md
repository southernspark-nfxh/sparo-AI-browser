## 2. 修复 P2：滚动采集增量检测（单独 commit）

- 第一步先定位：王海林单（`m-mvmeiuxj-2sc9n`）的连按 End 是模型驱动工具循环还是确定性采集手——`deepseek.ts:500/586` 有 repeatStop（`llm.repeatStop`），大概率是前者。**定位结论写进 commit message**。
- 若为模型驱动循环（预期）：增量检测实现为**工具结果附增量标注**——`page_text` 返回时对比同 tab 上次结果，附「较上次 +N 字」（deepseek.ts 工具结果组装处）；掐断消息同样转成 finding 回流脑区，不许空转收尾。不写本地滚动计数器、不做无限重试。
- 脑区侧：收到"无增量"finding 后由模型选换策略或 waiting_human；本地只保证 finding 到位，不替脑区决策。
- 测试：page_text 增量标注单测（同文本 +0 字、新增 +N 字）；repeatStop 掐断后 findings 里有记录。
