## 3. 现在卡在哪（三个硬事实）

### 3.1 R10 真机 0/6 的真凶：后台不取数

插桩证据（完整记录在 R10 任务书 §7）：

| 场景 | 观测 |
|---|---|
| 窗口最小化 / 被完全遮挡 | 30 秒里 `execute` 每次都**执行成功**，但表体 **0 行**；`performance` 里只有 JS 静态资源，**没有任何取数请求** |
| 手工开标签 + 窗口前台 | 3 秒出数据，6 秒稳定 8 行 |
| 手工开标签 + 窗口后台 | 12 秒才出首批，且 vxe 虚拟滚动只保留可见几行 |
| 加 `setBackgroundThrottling(false)` spike | **无效**，30 秒仍 0 行 |

**结论**：Chromium 对不可见窗口不绘制、页面也不发取数请求。这不是 R10 能修的，是 R9-6「读画面」方案的天花板。**R11 换方案 B（读接口）是唯一出路。**

## 7. 接手须知（今天踩过的坑，别重踩）

### 7.1 环境

- **`ELECTRON_RUN_AS_NODE=1` 会害 Electron 起不来**（进程活着但没窗口、没端口）。从工具里启动前必须 `unset ELECTRON_RUN_AS_NODE NODE_OPTIONS`。用户双击不受影响。
- 开发版端口 **3921**；安装版和开发版**共用数据目录**，安装版不退干净开发版起不来。
- `Add-Type` / `Invoke-Expression` / `WScript.Shell` 在这个环境**全被安全策略拦**，别想用它拉窗口。
- 后台 shell 启动的 Electron 窗口**不会自动显示**。

### 7.2 MCP 驱动

- `sidebar_chat { text }` 同步阻塞到整个侧栏任务跑完，超时要给够（≥330 秒）。
- **`execute` 永远跟活动标签走**，不带 `tabId` 就采不到指定标签 —— 这是采样卡住的根因。
- 标签会被应用「睡眠」成 `discarded: true`，之后 `execute` 返回 `ok:false` + message（不抛错），别把 `ok:false` 当成"页面没渲染"。
- 窗口最小化时，**页面不取数、不建 DOM** —— 任何靠读 DOM 的验收都必须在窗口可见时做。

### 7.3 纪律

- **改代码的人不许自己宣布"通过"**，绿不绿由发版窗口复核。
- **上一关没过，不发下一关任务**（R11 的 Part A/Part B 分段就是这么设计的）。
- **测试红一个都不打**，且判"是不是我改坏的"必须做**基线对照**（拿没改过的老代码跑同样文件）。
- 多窗口并行：**禁 `git stash` / `reset` / `checkout --` / 整文件格式化**，收工 diff 只许白名单文件。

`docs/ECOMMERCE-PHASE1-HANDOVER-2026-11-09.md` §3 说「R2–R9B 全部未提交」——**已过时**，Trae 收官时提交成 `dcf7d19` 了，工作区是干净的。交接单说 pollBox 有 3 行 `[dxm-poll]` 插桩——**也已清掉**。以本文为准。
